# zeus: Screen saturation and resolution patches

Evolution X 12 (Android 17) patches. Apply with `git am` inside each repository:

| Patch | Repository |
|---|---|
| Settings.patch | packages/apps/Settings (ee1dea4, also on branch `zeus-ahmet-a17`) |
| Evolver.patch | packages/apps/Evolver (0d2d9c7) |
| SettingsGoogle.patch | vendor/unbundled_google/packages/SettingsGoogle (df15f94) |

Defaults: saturation 200 %, resolution selector shown only on 1440 px wide panels.
